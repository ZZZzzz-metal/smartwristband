# 智能健康手环项目总览与 A—H 分工

_分工沿用 v0.2（2026-11-07）｜仓库整理：2026-11-09｜A—H 岗位不变，真实姓名待组内补齐，F 已认领。_

## 项目要做成什么

手环用 MPU6050 采集运动，完成计步、活动强度和久坐提醒；通过马达与屏幕提醒，并独立保存待同步记录。电脑 Qt 程序接收记录，保存到 SQLite，查询历史、显示 Qt Charts、导出 CSV。断网时手环本地继续工作。

核心链路：**采集 → 算法 → 久坐与提醒 → 六页交互 → 本地记录／缓存 → 可靠同步 → 存储查询／图表导出**。

本轮范围按[功能表](功能表.md)：15 项 P0、4 项 P1、3 项 P2 排除。编号前缀表示模块，不是岗位字母；唯一主责看负责人列，分工对应见[总约定](00-总约定.md)。本目录保留当前分工；历史更新说明在组内原协作包归档。

## 哪些先做，哪些后做

必做含计步／活动强度、45 分钟久坐震动与弹窗、六页、离线记录、可靠数据链与电脑查询展示。温度、心率血氧、疑似跌倒为扩展，独立调试并在不影响必做的前提下接入。X-04 移动端或轻量看板仅全部 P0 通过后评估，手机 App／第二平台边界待确认。功能表仍列有 X-03 疑似跌倒与取消，继续作为选做；本包不额外安排未列入功能表的功耗或结构设计扩展。

最终关键口径：5 组各 100 步且每组误差≤3 步；久坐 45 min±10 s，稍后／复位正确；通信解析正确、无重复、可补传；两端数据一致、可查询导出；另一组可独立复现。评分为 40／30／15／15，过程和文档同步留证据。

不做医疗诊断／治疗建议、电池管理与充电、复杂云平台／多租户、真实敏感身份、PC 实时告警中心。模拟数据和真实步数适用阶段待老师解释，联调必须标来源，并保留实测能力。
